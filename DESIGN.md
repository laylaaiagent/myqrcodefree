# DESIGN.md

## Visual style
- Clean, minimal UI — same visual language as namegenfree.com
- Light + dark mode
- Primary tool (QR generator) front and center on the page
- Reserve ad slot placeholders: top banner, sidebar, bottom banner (for AdSense later)

## QR Generator UI
- Tabs for QR type: URL, Text, WiFi, vCard, Location
- Live preview panel showing the QR code update as user types
- Color pickers: foreground + background
- Error correction level selector (L/M/Q/H)
- Optional logo upload (overlays center of QR)
- Download buttons: PNG, SVG
